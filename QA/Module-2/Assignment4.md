## Tool Selection

| Scenario                                     | Recommended Tool | Reason                                                                                                                                                                                                                                                                                             |
| -------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Measure TCP throughput between two hosts** | **iPerf3**       | iPerf3 is the standard tool for active network performance measurement. It can generate TCP traffic and report throughput, retransmissions, and packet loss. It's lightweight, easy to use, and works across platforms.                                                                            |
| **Capture packets from a Linux server**      | **tcpdump**      | tcpdump is a command-line packet capture tool available on all Linux distributions. It's lightweight, can capture in the background, and writes to pcap files for later analysis. It doesn't require a GUI, making it ideal for headless servers. Wireshark can then be used for analysis offline. |
| **Validate enterprise Wi-Fi performance**    | **IxVeriWave**   | IxVeriWave (now part of Keysight) is a specialised Wi-Fi test platform that simulates hundreds of wireless clients. It can measure roaming performance, throughput, and stability under load, which is critical for enterprise WLAN validation.                                                    |
| **Generate high-volume traffic**             | **TRex**         | TRex (Cisco) is a high-performance, stateful traffic generator based on DPDK. It can generate line-rate traffic with millions of concurrent flows, making it ideal for stress-testing routers, firewalls, and switches.                                                                            |
| **Analyze mirrored switch traffic**          | **Wireshark**    | Wireshark is the industry-standard protocol analyser. It supports deep packet inspection, filtering, and visualisation of captured traffic from SPAN/mirror ports. It's ideal for troubleshooting, security analysis, and protocol debugging.                                                      |
